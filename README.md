## 怎么加新作品

1. 封面图裁成**正方形**，放进 `img/` 文件夹。
2. 打开 `works.js`，复制一段 `{ ... }`，改成新作品的信息（文件开头有每一项的说明）。
   支持的加载器和 MC 版本写在 `versions` 里，网页会自动分组折叠。
3. 在 `updates.js` 最上面加一条更新公告（卡片上的「最新版本」「最后更新」会自动从这里取）。
4. 提交并推送，一两分钟后网站自动更新。
